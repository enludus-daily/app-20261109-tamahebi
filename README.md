# ころがれ！タマヘビ（app-20261109-tamahebi）

スネーク × ビリヤードのパズルゲーム。台のどこでもひっぱって離すと、ヘビのタマが転がる。転がった跡がそのまま胴体になり、胴体はクッションとして跳ね返す。球を食べると伸び、10 ショットで点を競う。

- 枠：006（`com.enludus.daily.006`。app-20261108-kosouji から使い回し）
- 元にした試作：Web 版（claude.ai の Artifact）。手触りと難しさは本人の感想（「むずい」）で直した版を移植した

同じ「ヘビ × ひっぱり × ビリヤード」のゲームは見つからなかった（近いのは Slide Ball Master・Struck! Snake VS Bombs）。

**値段**：Pro ¥480（約 $3.2）は、Brain It On! の本編 $3.99・Snakebird $3.99・Trick Shot 2 $2.99 と同じか安い。全部で ¥960（Pro＋パック 2 つ）でも、比べたアプリの本編＋広告消しより安い。**値段では負けていない。**

**負けているところ**
1. **見つけてもらえない**：日本のパズルはダウンロードの 30% 以上を占めるが、上位は広告費をかける海外の会社（[Sensor Tower](https://sensortower.com/ja/blog/state-of-mobile-puzzle-games-JP)）。広告費なしでは、月のインストールは数百本が現実的な見込み
2. **払わない 98% から何も入らない**：比べたアプリはどれも広告（とくにリワード広告）で払わない人からも収益を得ている。ハイブリッドカジュアルでは売上の 4〜6 割が広告という報告が多い（[Gamegrowthadvisor](https://gamegrowthadvisor.com/blog/2026-06-02-hybrid-monetization-mobile-games-iap-ads-guide-2026/)・[Gamigion](https://www.gamigion.com/2025-hybridcasual-market-overview-with-real-data/)）
3. **払う場面に届く人が少ない**：無料が 36 ステージと多く、Pro を出すのは 3-12 のあと。パズルの 30 日後に残る人は 5% 前後という数字もあり（出典の質は低い）、3-12 まで届く人はわずか
4. **ヒントを売れない**：比べたアプリはヒントで稼いでいる（Love Balls・Trick Shot 2）。ここでは消耗型を作らない決まりのため、おやつ・Pro・（入れれば）広告で開ける形

**売上の見込み（月）**：1 インストールあたり、課金 2% × 平均 ¥560 × 0.85 ≈ ¥9.5、リワード広告（入れた場合）1 人あたり一生で 8 回 × eCPM $3 ≈ ¥3.6、合計 ≈ ¥13。

- スクリーンショット：`-screenshotScene launch|worlds|stages|game|result|collection|capsule|pro|daily`
- ステージを作り直す：`tools/stagegen/run.sh`（Swift 6 が要る。Linux でも動く）
- ビルドとテストは GitHub Actions（`.github/workflows/ci.yml`）。TestFlight は `testflight.yml` を手動で
