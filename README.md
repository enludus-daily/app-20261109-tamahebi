# ころがれ！タマヘビ（app-20261109-tamahebi）

スネーク × ビリヤードのパズルゲーム。台のどこでもひっぱって離すと、ヘビのタマが転がる。転がった跡がそのまま胴体になり、胴体はクッションとして跳ね返す。球を食べると伸び、10 ショットで点を競う。

- 枠：006（`com.enludus.daily.006`。app-20261108-kosouji から使い回し）
- 元にした試作：Web 版（claude.ai の Artifact）。手触りと難しさは本人の感想（「むずい」）で直した版を移植した

## 遊びの中身

| 仕組み | 中身 |
|---|---|
| ステージ（96） | 8 ワールド × 12。7 かそく床／8 こわれるブロック（ワールドパック）。ワールドごとの仕掛け：1 ビリヤード場／2 ゴースト球（からだで跳ねてから食べる）／3 こおりの台とかべ／4 ワープの穴／5 うごくバンパー／6 ごちゃまぜ。おだいは「ぜんぶ食べる」「8 番球を食べる」 |
| 星 | 少ない打数ほど星が多い（★3 はステージ生成のときに見つけた打数） |
| ヒント（おてほん） | ★3 の打ち方を 1 打ずつピンクの線で見せる。近い向き・強さで引くと「ぴったり」になり、そのとおりに打てる。1 日 1 回無料、2 回目からおやつ 30、Pro はいつも無料。一度開けたステージはずっと見られる。おてほんの間はとくいをお休みにする（作ったときと同じ動きにするため）。物理は 1/240 秒の決まった刻みで進め、バンパーは頭が転がっている間だけ動くので、画面の速さに関係なく同じ結果になる |
| ステージの作り方 | `tools/stagegen`：同じ物理で、向き 48 × 強さ 6 のビームサーチで解き、向き ±1°・強さ ±3% ずらしても同じ数を食べる打ち方だけ採用。見つけた打ち方を `stages.json` に残し、テスト（`StageTests`）で再生して全ステージ星 3 で解けることを確かめる |
| きょうの台 | 日付から種を作り、だれが遊んでも同じ配置。10 ショットの点を競う |
| からだ＝クッション | 打った軌跡が胴体になり、頭が胴体に当たると跳ね返る |
| おやつ | ステージのはじめてのクリア 30・増えた星 1 つにつき 10／きょうの台：スコア ÷ 5 ＋ 星 1 つにつき 10 ＋ その日の 1 回目 50。ゲームの中だけのポイントで、売らない |
| カプセル | おやつ 120 でなかまを 1 匹。確率は画面に全部出す（ふつう 70%・レア 25%・スーパーレア 5%） |
| なかよし度 | 同じ子にまた会うと Lv が上がる（Lv5 まで）。Lv2・Lv4 できせかえ（パステル・よるいろ）、Lv3 でとくいが強くなる。Lv5 の子に会うとおやつ 60 が返る |
| なかまの数 | 24 匹：カプセル 18・Pro 限定 3・なかまパック 3 |
| うごくバンパー | ふだんはずっと動く（タイミングを考えて打つ）。おてほんのときだけ、止まっている間は待つ |
| とくい | すべてステージの攻略かおやつに効く：かそく床で速い（ユズ）・ブロックに強い（イシマル）・よく転がる（ゴマ・ルリ）・こおりですべりにくい（ミント）・ワープで加速（ソーダ）・口が大きい（レモン）・ゴースト球と仲よし（モモ）・ショット +1（ラムネ）・8 番でショット +1（クロスケ）・よく伸びる（ワタアメ）・よそく線が長い（ハッカ）・よくはずむ（ネオン）・おやつ増し（キャラメル・キラリ） |
| 毎日開く理由 | 次のステージ・星集め・きょうの台と続けた日数・カプセルとなかよし度 |

## 開発

- SwiftUI（Canvas と TimelineView で台を描く）。外部の依存なし
- ゲームの計算は `App/Sources/Engine/`（画面から切り離し、`Tests/` でテスト）
- スクリーンショット：`-screenshotScene launch|worlds|stages|game|result|collection|capsule|pro|daily`
- ステージを作り直す：`tools/stagegen/run.sh`（Swift 6 が要る。Linux でも動く）
- ビルドとテストは GitHub Actions（`.github/workflows/ci.yml`）。TestFlight は `testflight.yml` を手動で
